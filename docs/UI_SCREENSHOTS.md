# 真实界面截图

用户提供的 `界面截图.zip` 包含两张截图。本版只分发处理后的公开副本，不包含原压缩包或未遮挡原图。

| 页面位置 | 对应素材 | 当前状态说明 |
| --- | --- | --- |
| 工作台界面 / 工作台概览 | `workbench-overview.webp` | 来自长截图；运行中的一帧，不是全部步骤已完成 |
| 工作台概览放大 | `workbench-full.webp` | 完整长图，放大窗口可滚动查看 |
| 工程价值 / 工具调用片段 | `agent-tool-trace.webp` | 同一长截图中的调用记录，可见两次数据获取完成与组合启动 |
| 工作台界面 / 地图预览 | `map-preview-detail.webp` | 另一张截图的地图区域，可见实际影像与红色候选掩膜叠加 |
| 地图预览放大 | `map-preview-ui.webp` | 对应的完整文件与地图界面 |

## 处理方法

使用固定像素裁剪与不透明矩形遮挡。没有生成式修补、界面重绘、文字重写或运行状态更改。

- 长截图遮挡会话编号、两次输入中的精确坐标和参数、原始结构化输出、输入框任务参数。
- 地图截图遮挡本地绝对路径；保留图层开关、透明度、已有预测掩膜与底图原貌。
- 导出新的无原始 EXIF / 定位标签的无损 WebP。
- 裁剪与遮挡位置、原图 SHA-256 见 `assets/UI_PROCESSING.json`。

这些截图属于分别提供的历史界面材料，不据此认定它们为同一次执行，也不把状态栏时间等同于统一录制日期。长图运行中的事实保持原样，不能改成“全流程成功”。

## 维护

`content.json → media.workbench` 控制工作台概览；`fullSrc` 指向放大后的完整长图，`scrollFull: true` 开启长图滚动查看。`media.trace` 控制调用片段，`media.mapPreview` 控制地图截图。图注与模块内容集中在 `content.json → ui`。

截图文件更新时同步检查 `src`、`fullSrc`、像素尺寸、alt、图注与来源。不要将未经处理的原截图顺带加入公开仓库。
